# AI Portfolio — CLAUDE.md

## Project Overview

This is an AI portfolio for an AI course, hosted as a GitHub Pages site (GitHub.io). The portfolio showcases a range of AI use-cases: good, fun, and deliberately "evil" (adversarial/cautionary). The project lives in this directory.

## My Role

Help the user with:
- **Brainstorming** ideas for demos and showcases
- **Organisation** — structuring the project, managing files, naming conventions
- **Execution** — writing code, building demos, setting up integrations
- **Managing AIs** — local models, APIs, multi-model workflows
- **Portfolio website design** — layout, theme, UX, GitHub Pages setup

## Project Goals

- Build a compelling, well-designed portfolio website (GitHub Pages / github.io)
- Showcase a diverse set of AI use-cases across categories: good, fun, and evil
- Use a variety of AI tools: cloud APIs (e.g. Claude, OpenAI), local models (e.g. Ollama), and specialised tools
- Make each showcase self-contained and presentable

## Website Design Principles

- Hosted on GitHub Pages (github.io)
- Clean, modern design — should feel like a showcase, not a slide deck
- Each demo/project gets its own page or card
- Categories: Good / Fun / Evil (or similar framing)
- Mobile-friendly
- Minimal dependencies preferred — prefer vanilla HTML/CSS/JS or a lightweight static site generator

## Conventions

- All project files live in `/home/labuser/AI_portfolio_26/`
- Website source will live in a subdirectory (e.g. `docs/` or `site/`) for GitHub Pages
- Each demo/project gets its own subfolder
- Keep a running `ideas.md` for brainstorming

## Notes

- "Evil" use-cases should be framed responsibly — as cautionary tales or demonstrations of AI risks, not as how-to guides
- The user is open to using multiple AIs: local (Ollama, etc.) and cloud-based
- This is a course portfolio, so clarity of explanation matters — each demo should be understandable to an audience learning about AI
