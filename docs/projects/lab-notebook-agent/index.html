HOW IT WORKS
1

Write Daily Notes

Researcher writes quick .md entries each day — a to-do list and a notes section. No special format enforced. Files live in chronicle/<month>/<week>/.

2

Agent Discovers Files

The agent scans the chronicle directory, collects all .md files for the target month, and concatenates them into a single structured prompt. Skips summaries that already exist. python summarise.py month oct_2025

3

Local LLM Summarises

The combined entries are sent to Ollama running Gemma 3 12B locally via a structured prompt asking for accomplishments, findings, problems, and outstanding threads. POST localhost:11434/api/generate

4

Summary Written to Disk

The LLM's response is saved to summaries/monthly/<month>.md. The agent never overwrites existing summaries — you must delete manually to regenerate. summaries/monthly/oct_2025.md ✓
